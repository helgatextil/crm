# Инструкция по настройке доступа для Cursor Agent

Чтобы агент мог подключаться к вашему серверу `terminal.cdto.life` и синхронизировать файлы, необходимо добавить его публичный SSH-ключ в список доверенных ключей на сервере.

### Вариант 1: Если вы подключаетесь с Mac/Linux

Выполните эту команду в терминале на **вашем компьютере** (где лежит этот файл), заменив `user` на имя вашего пользователя (например, `root`):

```bash
ssh-copy-id -i cursor_agent_key.pub user@terminal.cdto.life
```

### Вариант 2: Ручная установка (на сервере)

1.  **Скопируйте содержимое файла `cursor_agent_key.pub`**.
    Оно выглядит так:
    ```
    ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAICihG8I273tVfagFB2GOuJ0/1AAuJRdN1Ub4B/9qmLa1 cursor-agent@workspace
    ```

2.  **Зайдите на сервер** по SSH:
    ```bash
    ssh user@terminal.cdto.life
    ```

3.  **Добавьте ключ** в файл `authorized_keys`. Выполните следующие команды на сервере:

    ```bash
    # Создаем директорию .ssh, если её нет
    mkdir -p ~/.ssh

    # Открываем файл для добавления ключа (или создаем новый)
    nano ~/.ssh/authorized_keys
    ```

4.  **Вставьте скопированный ключ** в конец файла (на новой строке).
    Нажмите `Ctrl+O`, `Enter` для сохранения, и `Ctrl+X` для выхода.

5.  **Настройте права доступа** (важно!):
    ```bash
    chmod 700 ~/.ssh
    chmod 600 ~/.ssh/authorized_keys
    ```

### Проверка

После выполнения этих действий сообщите агенту: "Ключ добавлен, пробуй снова".
