# crm

## Серверный хостинг

Для работы данной CRM системы (на базе Drupal) требуется серверная инфраструктура, соответствующая следующим требованиям:

### Системные требования

*   **Операционная система:** Linux (рекомендуется Ubuntu 20.04/22.04 LTS, Debian 11+ или CentOS Stream).
*   **Веб-сервер:** Apache 2.4+ или Nginx 1.14+.
*   **База данных:** MySQL 5.7.8+ / MariaDB 10.3.7+ или PostgreSQL 10+.
*   **PHP:** Версия 8.1 или выше.
    *   Необходимые расширения: dom, gd, simplexml, pdo, pdo_mysql/pdo_pgsql, и др.
    *   Рекомендуемый лимит памяти (memory_limit): 256MB (минимум), 512MB (рекомендуется).
*   **Управление зависимостями:** Composer 2+.

### Рекомендации по оборудованию (VPS/VDS)

Для стабильной работы CRM рекомендуется следующая конфигурация:

*   **CPU:** 2 ядра и более.
*   **RAM:** 4 ГБ и более.
*   **Диск:** SSD/NVMe, объем зависит от количества данных (минимум 20 ГБ).

### Настройка окружения

1.  Установите веб-сервер и PHP.
2.  Настройте базу данных.
3.  Используйте Composer для установки зависимостей (`composer install`).
4.  Настройте виртуальный хост, указывающий на директорию `web` (или корневую, в зависимости от структуры).
