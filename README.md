# crm

## Серверный хостинг

Серверный хостинг — это услуга предоставления вычислительных мощностей и дискового пространства для размещения веб-сайтов, приложений и данных в сети Интернет.

### Основные типы хостинга:

1.  **Виртуальный хостинг (Shared Hosting)**
    *   Самый доступный вариант.
    *   Ресурсы одного сервера делятся между множеством пользователей.
    *   Подходит для небольших сайтов и блогов.

2.  **VPS/VDS (Virtual Private/Dedicated Server)**
    *   Виртуальный частный сервер.
    *   Эмуляция отдельного физического сервера.
    *   Пользователь получает гарантированные ресурсы (CPU, RAM) и root-доступ.
    *   Подходит для растущих проектов и интернет-магазинов.

3.  **Выделенный сервер (Dedicated Server)**
    *   Аренда отдельной физической машины.
    *   Все ресурсы принадлежат одному клиенту.
    *   Максимальная производительность и безопасность.
    *   Подходит для крупных проектов с высокой нагрузкой.

4.  **Облачный хостинг (Cloud Hosting)**
    *   Ресурсы предоставляются кластером серверов.
    *   Высокая надежность и масштабируемость (можно быстро добавлять мощности).
    *   Оплата обычно производится за фактически использованные ресурсы.

### Ключевые характеристики при выборе:

*   **Uptime (Время безотказной работы):** Гарантия доступности сервера (например, 99.9%).
*   **Техническая поддержка:** Скорость и качество реакции на проблемы.
*   **Безопасность:** Защита от DDoS-атак, регулярные бэкапы, SSL-сертификаты.
*   **Скорость:** Пропускная способность каналов связи и тип дисков (SSD/NVMe).
